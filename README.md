# Shopping App 🛒

## 📖 Overview
A simple shopping app built using **Flutter**.  
The app demonstrates clean UI design, navigation, and state management for an e-commerce experience.

## ✨ Features
- Browse products
- Add items to cart
- Mark favourites
- Responsive UI for mobile

## 🛠 Tech Stack
- Flutter & Dart
- Material Design Widgets

## 🚀 Setup & Run
```bash
# clone this repository
git clone https://github.com/YusifJs/shopping_app_sxmTask.git
cd shopping_app_sxmTask

# install dependencies
flutter pub get

# run on device or emulator
flutter run
